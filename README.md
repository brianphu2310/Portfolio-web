# Brian Phu — Portfolio Website

Personal portfolio site for Brian Phu, a data analyst based in Sydney. It presents my Tableau dashboards and Streamlit apps, with an about section and contact links.

**[▶ View the live site](https://delicate-manatee-7e78ab.netlify.app)**

## What's on the site

- **About**: background and approach
- **Tableau Dashboards**: published Tableau Public work
- **Streamlit Apps**: deployed analytics apps
- **Contact**: email, LinkedIn, GitHub

## Tech

A single self-contained static page (`index.html`): HTML, CSS and JavaScript with no build step and no dependencies. Fonts (Syne, Space Mono) load from Google Fonts. Hosted on Netlify.

## Run locally

```bash
git clone https://github.com/brianphu2310/Portfolio-web.git
cd Portfolio-web
python -m http.server 8000     # then open http://localhost:8000
```
